# 仕様書: YouTube Transcription Web App

## 1. 目的
本仕様は、YouTube 動画の音声を抽出し、文字起こし・校正・Q&A・管理までを一貫して提供する
Web アプリケーションの現行要件を定義する。

## 2. プロダクト概要
- YouTube URL から音声抽出を行う。
- OpenAI 音声認識 API を用いて日本語・英語の文字起こしを行う。
- LLM による校正（proofread）と Q&A を行う。
- TXT/SRT/VTT 形式で出力できる。
- フォルダツリーとタグで結果を整理・検索できる。

## 3. スコープ
### 対象
- バックエンド API（FastAPI）
- 非同期処理（Celery + Redis）
- 永続化（PostgreSQL + Alembic）
- フロントエンド UI（Next.js）
- Docker 実行とローカル no-Docker 実行スクリプト

### 非対象
- YouTube 制約を超える取得保証（地域制限・DRM・非公開動画など）
- OpenAI API 側制限の回避保証
- 外部サービス障害時の完全自動復旧

## 4. 機能要件
1. ジョブ作成
- 単一 URL とバッチ入力（URL リスト / CSV / プレイリスト・チャンネル展開）を受け付ける。
- ジョブ作成時に入力バリデーションを行い、不正入力は 4xx を返す。

2. 非同期処理
- 文字起こし・校正・Q&A は非同期ジョブとして処理する。
- キュー投入失敗時は失敗理由を明示し、孤立した pending ジョブを残さない。
- バッチ入力で投入した待機中または実行中の文字起こしジョブを、UI から取消できる。

3. 進捗と結果
- ジョブ状態・進捗・エラーメッセージを API から取得できる。
- ユーザー操作で取消されたジョブは canceled として判別できる。
- 文字起こし結果、校正結果、Q&A 結果を保存・参照できる。

4. ライブラリ管理
- Item/Folder/Tag モデルで結果を整理できる。
- 検索、フィルタ、並び替え、一括操作をサポートする。
- 記事（Item）をドラッグ&ドロップでフォルダへ移動できる。

5. 出力
- TXT/SRT/VTT エクスポートを提供する。

6. ノート編集
- Note タブで選択文字列に太字・黄色ハイライトの装飾を付与できる。
- ノート編集画面で装飾結果のプレビューを確認できる。

## 5. 実行プロファイル要件
1. Docker プロファイル
- docker-compose.yml で postgres / redis / migrate / api / worker / frontend を起動できる。

2. ローカル no-Docker プロファイル
- run20_start_backend_W.O._docker.{sh,bat} で FastAPI をホスト実行できる。
- run21_start_frontend_W.O._docker.{sh,bat} で Next.js をホスト実行できる。
- DB/Redis/worker が未起動の場合は preflight/health で明示エラーとする。

## 6. 非機能要件
- 可観測性: /health と構造化ログで障害要因を判別できること。
- 運用性: 起動スクリプトが依存不足を早期検知し、曖昧な失敗を避けること。
- 保守性: ルータ、サービス、ワーカー、UI を責務分離すること。

## 7. 受け入れ基準
1. 依存サービス（DB/Redis/worker）が健全なら、ジョブ作成が成功する。
2. 依存サービスが不健全なら、run20/run21 または API が対処可能なメッセージを返す。
3. バッチ入力から複数ジョブを投入し、状態追跡できる。
4. 結果をライブラリで検索・整理し、エクスポートできる。

## 8. 制約
- 外部 API や YouTube 側制約により処理失敗は発生し得る。
- 運用上の正しさは、DB/Redis/worker の健全性に依存する。
